# Получить EXE и APK без скачивания инструментов

## Почему так

Компиляция Flutter-приложения требует ~16 GB инструментария (Flutter SDK,
MSVC, Android SDK). Если у вас нет места — эти инструменты живут на серверах
GitHub, а вы получаете только **готовые** `.exe` и `.apk` (~55 MB вместе).

## Шаги

### 1. Аккаунт GitHub
https://github.com/signup — бесплатно, 0 байт локально.

### 2. Новый репозиторий
- https://github.com/new
- **Repository name**: `negern` (или любое)
- **Public** (приватные тоже соберутся, но расход минут CI ограничен — 2000 мин/мес бесплатно)
- Галочки "Add a README" / ".gitignore" / "license" — **не ставьте**, они у нас свои
- Create repository

### 3. Загрузка исходников
На пустой странице репозитория есть ссылка
**"uploading an existing file"**. Кликните.

В Проводнике Windows откройте `C:\Users\sanechka  krytoi\Documents\negern\`.
Выделите ВСЁ содержимое (`Ctrl+A`) — `app/`, `docs/`, `scripts/`,
`.github/`, `Dockerfile`, `.gitignore` и т.д. — и **перетащите в окно
браузера**. Chrome/Edge примет папки рекурсивно.

Внизу страницы: коммит-сообщение `initial` → **Commit changes**.

### 4. Автоматическая сборка
На странице репо откройте вкладку **Actions**. Там запустился workflow `CI`
с тремя задачами:
- `analyze-test` (~3 мин)
- `build-apk` (~10 мин)
- `build-windows` (~8 мин)

Дождитесь зелёных галочек.

### 5. Скачивание артефактов
Кликните по успешному запуску CI → внизу страницы секция **Artifacts**:
- `negern-release-apk` — APK для Android (~30 MB)
- `negern-windows` — ZIP c `negern.exe` + dll + data/ для Windows (~25 MB)

### 6. Установка
- **Android**: скопируйте APK на телефон, откройте, разрешите установку из
  неизвестных источников.
- **Windows**: распакуйте ZIP куда хотите → запустите `negern.exe`. Программа
  **портативная**, ставить ничего не надо.

## Если не хочется GitHub

Альтернатив без локальных ~16 GB **не существует**. Все сервисы
(Codemagic, AppFlow, Bitrise) работают по той же схеме: загружаете исходники
к ним на сервер, они собирают, вы качаете готовое.

Единственный способ собрать полностью локально — вариант из `BUILD.md`
(установка Flutter + VS Build Tools + Android SDK).
